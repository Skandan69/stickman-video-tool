Scene Engine — Beta

A separate, experimental page — the main tool above is untouched. This proves out one idea: composing a pose from physical building blocks (reach, wrap-around) instead of only picking from the ~50 pre-built actions.

What you're looking at: type any description below and Claude AI plans the scene — background, weather, up to five characters, and any of the ~50 existing actions (walk, dance, yoga, drive, whatever fits) — each person can be doing something different. Say "hugging from behind" (with exactly two people involved) and the second character's arms are computed live every frame with inverse kinematics, reaching toward wherever the first character's torso actually is — a pose that doesn't exist anywhere in the main tool's action library. Mention "jeep" or "4x4" to re-skin a ride action with jeep art instead of the default. Still early: hugging from behind is the only cross-character interaction built so far — everything else (any single action, any group of up to five independent actions side by side) works, but other interactions (sitting together, face-to-face, etc.) beyond pairs aren't wired up yet. If the AI call isn't configured or fails, a simple keyword-matched scene shows instead so the page still responds.
