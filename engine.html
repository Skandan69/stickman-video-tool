Scene Engine — Beta

A separate, experimental page — the main tool above is untouched. This proves out one idea: composing a pose from physical building blocks (reach, wrap-around) instead of only picking from the ~50 pre-built actions.

What you're looking at: a duo ride with one character hugging the other from behind — this exact pose does not exist anywhere in the main tool's action library. The rider uses a real, unmodified ride action. The hugger's arms are computed live every frame with inverse kinematics, reaching toward wherever the rider's torso actually is — not a fixed pre-tuned position. Try a description below: it currently reacts to a vehicle (say "jeep" or "4x4" for a jeep, anything else defaults to a bicycle) and a background (name any of the main tool's backgrounds, e.g. "beach", "forest", "desert"). The hug interaction itself is still fixed for now — full AI-composed scenes (any interaction, not just this one) are the next phase.
