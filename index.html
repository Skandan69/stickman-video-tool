Stickman Video Studio — Prototype

A free, no-credits stick-figure animation tool. Build a timeline out of segments — each with an action per character and an optional line of dialogue — then export a real .webm video.

🎨 Design Your Own Scene

Add as many characters as you want below, then hand-design each one's moves frame by frame — a boxing match, a dance routine, anything you can picture — instead of only picking from the built-in action list. The live preview shows the real background and every other character while you work, and you can save any move you build to reuse later.

✎ Flipbook Animator

Draw your own frame-by-frame animation from scratch — sketch a frame, click "+ Add" for the next one (the faint outline of the last frame, the onion skin, stays visible so you can line up the motion), then play it back or export it as a real .webm video.

Design a Move

Drag the purple dots on the hands, feet, and head directly on the preview to pose the character — or use the sliders for precise control. Once you're happy with a pose, click "Add keyframe". Add a few keyframes (e.g. guard → jab → kick → guard) and the tool smoothly animates between them, looping, so your move plays like a real designed sequence.

This runs entirely in your browser — no AI credits used. The description box uses built-in keyword understanding (not a live AI call) to recognize actions like walk, sit, drink coffee, talk on the phone, wave, dance, jump and fly a kite, plus a duration like "2 minutes", seating like "sofa", animals like "dog" or "cat", and vehicles like "car" or "bicycle" — it builds a timeline you can still fine-tune below. Add as many timeline segments as you want; the exported video length always matches the full timeline.
